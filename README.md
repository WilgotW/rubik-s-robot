*Rubiks Cube Robot*

The purpose of this robot is to be able to scan, calculate solution and solve a rubiks cube. The robot has several different parts that interconnect: 
Mechanical (Robot Arm, color sensor, servos), 
Electronics (Custom made PCB with a STM32 chip), 
programming (Both computer program for solving the Rubiks cube as well as C programming for the STM32 IC)

This projects has divided all the files into sorted folders for each part of the robot told above.
